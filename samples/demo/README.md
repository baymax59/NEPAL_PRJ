# Demo cases (FICTIONAL)

**Every document in this folder is invented** for demonstrating the system. No real case, person or police station is described; each file says so in its first line. They refer to real laws and well-known judgments only as a real document would.

| File | Format | Topic | What the system finds (rehearsed 7 Nov 2026) |
|---|---|---|---|
| `CASE-2001-murder-appeal-FICTIONAL.pdf` | PDF | Murder conviction resting on circumstantial evidence: "last seen together", body recovered on a disclosure statement | **Boby v. State of Kerala** first (relevance 96; shared Sections 302 and 201 IPC and Section 27 Evidence Act), then other murder appeals; 12 similar cases |
| `CASE-2002-land-acquisition-FICTIONAL.docx` | Word | Farmers' land acquired in 1998, never paid for or taken: has the acquisition lapsed? | **DDA v. Surender Singh** (96), Govt. of NCT of Delhi v. Khajan Singh, Dayanand, Agra Development Authority: the "lapse" judgments |
| `CASE-2003-default-bail-FICTIONAL.txt` | Text | No charge sheet within 90 days: default bail | **V. Senthil Balaji** (100), **Qamar Ghani Usmani** (92), Waheed-ur-Rehman Parra (85), all sharing Section 167 CrPC |
| `../CASE-1042-fictional.txt` | Text | A business payment dispute turned into a cheating FIR; petition to quash | **Vijay Kumar Ghai v. State of West Bengal** first (100; shared Sections 406, 420 and 120B IPC) |
