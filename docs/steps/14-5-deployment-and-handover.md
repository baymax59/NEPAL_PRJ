## 6. The code, explained

### Deactivation

The `users.is_active` flag existed since Step 10: a deactivated user can't log in, and tokens issued earlier stop working. Until now there was no command to set it. `--deactivate`/`--reactivate` set it, require `--by <administrator>`, and record `user.deactivated` / `user.reactivated` in the audit log. The user's own history is kept.

### FIR-style citations (`provisions.py`)

Court judgments write "Section 302 IPC"; FIR registers write "BNS 318(4), 316(2)". The new pattern reads an Act **abbreviation followed directly by section numbers**, and is deliberately narrow:
- only the criminal codes (IPC, CrPC, BNS, BNSS, BSA), so "the SEBI Act 15 times" isn't read as a citation;
- only 1–3 digit numbers, so the year in "IPC 1860" or "CrPC 1973" never becomes a section;
- not inside a longer word ("NIPC 420").

Checked on the real data: re-extracting all 100 Supreme Court judgments gave **exactly the same 414 provisions as before**, with nothing added or lost. So it adds nothing false to court text, and it now finds "Section 318 BNS" and "Section 303 BNS" in the fictional FIRs.

## 10. Common errors and fixes

| Symptom | Cause | Fix |
|---|---|---|
| `--by <administrator> is required` | Deactivation without saying who did it | Add `--by <your username>` |
| Smoke test: `FAIL search` on a new installation | The default search is about the Supreme Court sample | `--search "<words that occur in your cases>"` |
| Smoke test: `FAIL login: HTTP 422` | No password reached the script (e.g. piped through a PowerShell function) | Type it when asked, or pipe it straight into `docker compose ... --password-stdin` |
| A second installation on the same computer takes over the first one's containers | Same project name (`name: case-search` in `docker-compose.yml`) | Give the second one its own: `docker compose -p <other-name> ...` and different ports |
| A citation like "BNS 318(4) (cheating), 316(2)" gives only Section 318 | The words in brackets end the list of numbers | Expected (cautious by design). The full list is in the record's category field |
